# Evaluation experiments at /eval

- Objective: add an isolated experiment page for retrieval and job-fit generation, with selectable embedding/provider models. User confirmed existing workspace data and existing Claude/GPT/Gemini assessments.
- Tool/model: Codex, GPT-6 session. Branch unavailable: this workspace has no Git repository. No subagents used.
- Skills: agents/skills/project-manager/SKILL.md, frontend-engineer/SKILL.md, backend-engineer/SKILL.md, test-engineer/SKILL.md; evaluation-manager file has the documented duplicated PM content, so AGENTS evaluation rules applied. OpenAI Docs verified the two embedding choices against the official embedding guide.
- Backend: backend/schemas/experiments.py, backend/evaluation/experiments.py, backend/routers/experiments.py, router registration and /eval SPA route. providers.evaluate_jobs gains optional log_jobs=False for experiment calls, preserving the production default.
- Frontend: EvalView.vue, router.ts, main.ts direct /eval startup exception, App.vue navigation and mobile wrapping, PrivacyView.vue; generated frontend/openapi.json and types/api.d.ts. Synthetic mocks in mocks/experiments.ts registered by handlers.ts.
- Tests: tests/test_experiments.py (11 cases), frontend/tests/experiments.spec.ts (2 cases), frontend/e2e/experiments.spec.ts (2 workflows).
- Contracts: six /api/experiments routes; fingerprint-bound requests, phase and model selections, K 1–20, strict boolean human labels. Source pools capped at 500; no automatic scraping/model calls on page open. One isolated experiment worker; explicit cancellation, partial/failure states, no provider fallback. Reports/settings kept in memory up to 24 hours/latest 20, cleared on restart, exportable as JSON.
- Comparison decisions: use stored focused retrieval text for exact cosine + existing weighted BM25/RRF; no production index writes, seniority/dismissal partition, or assessment cache reuse. Shared requirement extraction can reuse its cache. All generation providers receive the first selected embedding model's shortlist; generation-only uses the dataset's first K. Saved-results-only fallback is labeled; expired scoped pools error. Missing-URL identities retain distinct postings. Late polls cannot undo cancellation; expired reports release the form.
- Verification: final scripts/check.sh with job-tracker Python and tracing disabled passed: 260 Python, 79 frontend, 1 legacy, contract generation, typecheck and build. Initial full browser suite: 28/32 passed; four failures exposed dropdown-label and mobile-header issues. After fixes all four passed. Final two experiment browser workflows passed again after lifecycle fixes, including axe, narrow layout, labels, model choice, refresh, cancellation and rejected starts. Thus all 32 browser scenarios have passing evidence across full/focused runs; the entire suite was not repeated after the final fixes.
- Approval: one browser rerun was temporarily blocked by automatic-review usage limits; user asked to continue and the retry was approved and completed. No blocker remains.
- Documentation: docs/evaluation-experiments.md, README, frontend/README, context-document route/addendum, privacy page. Pre-existing unrelated inaccuracies in historical context sections were not rewritten; docs/images/api-documentation.md referenced by PM skill is absent.
- Limitations: no live model calls or human-labeled quality benchmark was performed. Timings include retries/extractor/cache-order effects; no cost/token metrics. Generation choices are the three configured provider model IDs, not arbitrary model overrides. These limitations are visible in the guide.
